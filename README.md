# Alberto Gracia Martelo

**IoT & Embedded Systems Engineer | HW/SW Integration | Engineering Physicist**

I build systems that connect sensors, firmware, electronics, and software to physical hardware. My work spans industrial safety, on-device AI, device management, and electromechanical prototypes. I focus on reliable integration, field conditions, and clear technical documentation.

## Selected Work

### [Tenty — Rugged Android Industrial Safety System](https://albertogracia.dev/projects/tenty)

I develop the Android application and its integration with Ulefone rugged devices for workplace safety. The system connects device sensors, cameras, physical controls, telemetry, geofencing, and offline workflows. Local computer vision supports on-device operation.

- Role: Android and device integration engineer
- Stack: Kotlin, Android, rugged hardware, sensors, cameras, telemetry

### [Watchman — Edge AI PTZ Camera System](https://albertogracia.dev/projects/watchman)

I develop a local AI and computer vision system that interprets operator requests and controls a physical PTZ camera. Operator interaction is connected through WhatsApp. The portfolio case study distinguishes implemented camera control from conceptual hardware designs.

- Role: Edge AI and physical system developer
- Stack: Python, computer vision, Gemma 4, PTZ control, WhatsApp

### [ChessProject — Autonomous Chessboard](https://albertogracia.dev/projects/chessproject)

An STM32-based electromechanical chessboard with XY motion, stepper motors, servo-lift electromagnet, endstops, and USART communication. Python/Flask software integrates Stockfish and python-chess.

- Role: Embedded firmware and hardware integration
- Stack: STM32/HAL, C, timers/PWM, USART, Python/Flask
- [Technical overview](https://albertogracia.dev/docs/ChessProject.pdf) · [Source repository](https://github.com/algracia/ChessProject-Autonomous-Chessboard-STM32-XY-Motion-)

### [Mechanical CAD Assemblies](https://albertogracia.dev/projects/cad-assemblies)

A wafer dispenser and a tracked tank, presented through assembly drawings, exploded views, and CAD videos. The work documents component relationships and prototype construction.
